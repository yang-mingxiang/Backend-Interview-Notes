在 GitHub 网页版里，可以一步完成"新建文件夹 + 上传 PDF"。

方法一：直接上传时顺便建文件夹（推荐）

打开你的仓库（项目）主页，进入你想放文件夹的位置（比如根目录）。
点击右上方的 Add file → Create new file。
在文件名输入框里输入 文件夹名/ ，输入斜杠 / 后，文件夹会自动生成（例如 docs/）。
此时 GitHub 要求文件夹里至少有一个文件，所以继续在斜杠后输入一个临时文件名，例如 docs/README.md，内容随便写一点，然后点 Commit changes 提交。
提交后进入刚建好的 docs 文件夹，点击 Add file → Upload files。
把本地的 PDF 拖进网页，或点击 choose your files 选择文件。
等待上传完成，在下方填写提交说明（可选），点击 Commit changes 即可。
